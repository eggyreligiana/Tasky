# ✅ Tasky – Aplikasi To-Do List Sederhana

Tasky adalah aplikasi berbasis Android untuk mencatat dan mengelola daftar tugas harian. Pengguna dapat menambah tugas, menandai tugas yang sudah selesai, dan menghapus tugas yang tidak diperlukan. Aplikasi ini dikembangkan menggunakan Kotlin dan Jetpack Compose di Android Studio dengan antarmuka yang sederhana dan mudah digunakan.

## 📝 Fitur & Layar Aplikasi

- **Tambah Tugas**: Mengetik tugas baru pada kolom input lalu menekan tombol "Tambah".
- **Tandai Selesai**: Mencentang tugas sehingga teks menjadi abu-abu dan tercoret.
- **Hapus Tugas**: Menghapus tugas dari daftar dengan tombol "Hapus".
- **Penghitung Tugas**: Menampilkan jumlah tugas yang belum selesai.
- **Tampilan Kosong**: Menampilkan pesan petunjuk saat belum ada tugas.

## 🛠️ Komponen UI & Teknologi

- **Bahasa Pemrograman**: Kotlin
- **IDE**: Android Studio
- **Build System**: Gradle
- **Antarmuka**: Jetpack Compose (Material 3)
- **Komponen UI**: Scaffold, TopAppBar, OutlinedTextField, Button, TextButton, Checkbox, Card, dan LazyColumn

## 🚀 Cara Menjalankan Aplikasi

1. Clone atau download repository ini.
2. Buka proyek **Tasky** menggunakan Android Studio.
3. Tunggu proses Gradle Sync hingga selesai.
4. Jalankan aplikasi melalui emulator atau perangkat Android.
